DMS2 - SoSau Media

SoSau Media is a project featuring the combination of 3D,2D with UI/UX experiences. The projects featuring the exploration in prototyping, animation via Figma software to create a website for an art gallery event.

My main work in this project was to create the UI/UX design for some activities in the event such as the photobooth and timeline. I also took part in arranging the website layout.
